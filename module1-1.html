Les différents types de données

Variable Quantitative (continue et discrète)

Une variable quantitative est une variable qui peut être exprimée par un nombre, une quantité. Une variable discrète est une variable qui peut prendre uniquement certaines valeurs d'un intervalle de nombres réels. Généralement, les valeurs admissibles ne sont que les nombres entiers. Une variable continue est une variable qui peut prendre toutes les valeurs possibles d'un intervalle de nombres réels.

Variable Qualitative (nominale et ordinale)

Une variable qualitative exprime une valeur qui ne représente pas une quantité. Une variable indépendante dans un problème est le paramètre qui varie sans être influencé par les autres paramètres du problème. En général, on représente la variable indépendante par la lettre x. Une variable dépendante dans un problème est le paramètre du problème qui varie sous l'influence de la variable indépendante. En général, on représente la variable dépendante par la lettre y.

Certains types de diagrammes

Diagramme à bandes

Un graphique utilisant des bandes/barres pour comparer différentes catégories. Plus la bande est longue ou haute, plus la valeur est grande. Pour comparer le nombre d’élèves dans différentes classes : 10e année = 120 élèves, 11e = 100, 12e = 80.

Histogramme

Un graphique qui regroupe des données numériques en intervalles. Les barres se touchent, car les données représentent des valeurs qui se suivent. Pour montrer la distribution des notes d’un examen : 0–10, 11–20, 21–30, etc.

Diagramme circulaire

Un cercle divisé en secteurs. Chaque secteur représente une partie d’un tout, généralement en pourcentage. Pour montrer comment les élèves d’une école se déplacent : 40 % autobus, 30 % voiture, 20 % marche, 10 % vélo.

Diagramme à ligne brisée

Un graphique utilisant des bandes/barres pour comparer différentes catégories. Plus la bande est longue ou haute, plus la valeur est grande. Pour comparer le nombre d’élèves dans différentes classes : 10e année = 120 élèves, 11e = 100, 12e = 80.
